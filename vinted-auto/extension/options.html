Vinted Auto · Options

Tout reste dans ton Chrome. La clé API n'est envoyée qu'à Anthropic.

Qui écrit les réponses

Modèles : phrases toutes faites selon la question (vraies ?, prix, photos, réservation, dispo...). Question pas reconnue : rien n'est envoyé, tu reçois une notification.
IA locale : les questions pas reconnues sont écrites par une IA gratuite qui tourne sur ton PC (Ollama), avec la personnalité plus bas.

Décoché (conseillé) : les réponses de l'IA locale restent en brouillon, même en mode Auto. Un petit modèle invente parfois un détail.

Claude (seulement si moteur Claude)

À créer sur console.anthropic.com > API Keys. Payant à l'usage.

Personnalité (IA locale et Claude)

Comment l'IA répond. Les règles anti-IA sont ajoutées automatiquement après ce texte. Le mode gratuit utilise ses propres phrases, tirées de cette personnalité.

Tester sans toucher à Vinted

Gratuit en modèles et IA locale. Avec Claude, coûte une réponse.
